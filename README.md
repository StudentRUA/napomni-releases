# Напомни

Установщики приложения «Напомни» для Windows и Android.

## Скачать

Установщики появятся на [странице выпусков](https://github.com/kop-kam/napomni-releases/releases) после публикации первой версии. Пока выпуск не опубликован, ссылка на последний выпуск может быть недоступна.

Для Windows нужен файл `Napomni-Setup-<версия>-x64.exe`, для Android — `Napomni-<версия>-android.apk`.

## Обновление

В приложении откройте «Настройки» → «Проверить обновления». Проверка сообщает о последнем стабильном выпуске; скачивание и установка запускаются пользователем вручную.

Перед установкой на Windows выйдите из программы через меню трея. На Android устанавливайте APK поверх существующего приложения. При совместимом пакете и подписи записи и настройки сохраняются. Перед обновлением рекомендуется экспортировать данные и настройки.

В каждом выпуске публикуются установщики, `napomni-update.json` и `SHA256SUMS.txt`. Исходный код, ключи подписи и пользовательские записи в этом репозитории не размещаются.
