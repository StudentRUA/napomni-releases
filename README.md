## Обновление

В настройках доступна ручная проверка и тихая автоматическая проверка новых версий. Кнопка «Обновить» загружает и проверяет установщик. Android дополнительно запрашивает системное подтверждение установки. Данные сохраняются при установке поверх совместимой предыдущей версии; перед обновлением рекомендуется экспортировать записи и настройки.

Новые установки не содержат демонстрационных записей. В выпуске приложены `napomni-update.json` и `SHA256SUMS.txt`.

## Google

Google-подключение переведено в Production: добавление аккаунтов в список тестовых пользователей не требуется. Каждый пользователь самостоятельно разрешает доступ через Google. Для используемых областей calendar.app.created и drive.appdata Google не требует проверки чувствительных или ограниченных областей. Корпоративные политики аккаунтов могут ограничивать подключение. Реальная синхронизация на устройствах пока не проверена; вход владельца на Windows подтверждён пользователем. Локальная синхронизация по QR доступна отдельно.
