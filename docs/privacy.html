Политика конфиденциальности приложения «Напомни»


Дата редакции: 5 ноября 2026 года.
Разработчик: Александр Герасимов.

Назначение и локальные данные

«Напомни» — приложение для задач, заметок, событий и напоминаний на Windows и Android. Названия, тексты, даты, повторы, статусы выполнения и настройки хранятся на устройстве. Экспорт создаёт файл в выбранном пользователем месте; пользователь самостоятельно определяет, кому его передавать. Разработчик не получает доступ к записям только из-за установки приложения.

Подключение Google

Подключение необязательно и начинается по действию пользователя через экран согласия Google. Приложение использует разрешение calendar.app.created для создания отдельного календаря и чтения, создания, изменения и удаления событий в календарях, созданных приложением. Оно не запрашивает общий доступ ко всем календарям аккаунта.

Для синхронизации устройств через Google Drive используется разрешение drive.appdata: снимки записей сохраняются в скрытой папке данных приложения в Google Drive пользователя. Это разрешение не даёт приложению читать произвольные файлы Google Drive. Google Calendar и Drive подключаются отдельно. Тексты событий и заметок могут содержать личную информацию; при включении соответствующей синхронизации она передаётся Google для выполнения выбранной функции.

Данные Google используются для предоставления функций календаря и синхронизации. Они не используются разработчиком для рекламы, продажи, передачи брокерам данных или обучения универсальных моделей искусственного интеллекта. Использование и передача информации, полученной через Google API, должны соответствовать Google API Services User Data Policy, включая требования Limited Use: https://developers.google.com/terms/api-services-user-data-policy.

Токены авторизации используются для обмена с Google. На Windows сохранённые токены защищены средствами операционной системы. Не передавайте файлы подключения, токены и резервные копии посторонним.

Голос и камера

Микрофон используется для голосового ввода и, при отдельном включении, прослушивания фразы вызова. Эти функции отключаются отдельно. В Windows используется встроенное локальное распознавание. В Android доступность и способ распознавания зависят от выбранной функции и системного сервиса; если используется системное распознавание, обработка регулируется также настройками и политикой его поставщика. Камера используется при запуске сканирования QR-кода для связи устройств.

Локальная синхронизация и обновления

Связанные устройства могут обмениваться записями по локальной сети. Доступ к устройствам и кодам связывания следует предоставлять только доверенным лицам. При проверке и загрузке обновлений приложение обращается к GitHub; GitHub получает технические сведения сетевого запроса, например IP-адрес, в соответствии со своей политикой конфиденциальности: https://docs.github.com/site-policy/privacy-policies/github-privacy-statement.

Отключение и удаление

Отключение Google в приложении прекращает дальнейший обмен, но само по себе не удаляет локальные записи, события в Google Calendar или сохранённые снимки Drive. Доступ можно отозвать в настройках аккаунта Google: https://myaccount.google.com/connections.

Локальные записи удаляются средствами приложения; удаление данных приложения средствами ОС также удаляет его локальное хранилище, но не экспортированные файлы. Облачные данные удаляются отдельно: события или календарь — в Google Calendar, скрытые данные приложения — средствами управления приложениями Google Drive. Ранее экспортированные копии удаляются пользователем там, где они сохранены. Изменения и удаления записей при включённой синхронизации обрабатываются механизмом обмена, включая служебные отметки удаления.
